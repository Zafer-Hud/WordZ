# WordZ Kelime Bulmaca

Sıfırdan Kotlin ve Jetpack Compose ile geliştirilen Android kelime bulmaca oyunu.

## İlk prototip
- Harf çarkı
- Parmağı sürükleyerek kelime oluşturma
- Doğru kelime kontrolü
- Bulunan kelimeleri açma
- Harfleri karıştırma
- Bölüm tamamlama ve sonraki bölüme geçiş

## APK
`main` dalına yapılan her güncellemede GitHub Actions otomatik olarak `WordZ-debug.apk` üretir. APK, ilgili workflow çalışmasının **Artifacts** bölümünden indirilebilir.
